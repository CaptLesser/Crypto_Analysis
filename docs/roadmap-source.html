public boundary

What this map excludes

The Source Map points to public code only. It does not publish generated feature values, forecast rows, regime labels, model states, logs, local reports, private data, or local filesystem locations.

Forecasting, regimes, and features are described as source-visible engineering components. The page does not make trading, investment, runtime, data-coverage, or model-performance claims.

IncludedExcluded
