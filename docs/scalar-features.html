feature overview

Feature families

The public source separates feature generation into three related families: Scalar Features, Regime Features, and Relationship Features.

Each family produces historical numeric records intended for downstream state analysis or numeric forecasting. The public site describes schemas, intervals, and source paths; it does not publish generated values.

This page keeps the compatibility filename scalar-features.html, but the visible page title is now Features.

regime feature outputs

Regime feature outputs

Regime Features are numeric and categorical source artifacts used to prepare state workflows. The source contract separates market features, pairwise relationship features, cross-asset summary features, eligibility snapshots, and universe snapshots.

Market feature code defines primitive market feature families and columns. Asset-state code defines feature pools and preprocessing options for behavioral axes. Cross-asset code defines model-facing relationship feature families for meso and macro bands.

relationship feature outputs

Relationship feature outputs

Relationship Features start with Relationship Discovery method comparisons and schemas, then feed cross-asset state feature families.

The source compares rolling correlation, beta-to-core-basket, residual return, residual correlation, volatility similarity, and feature-distance similarity by default. A lead-lag diagnostic exists but is disabled unless explicitly requested in the method config.

Terms

Plain-language source notes.

feature column
A named numeric output column used by downstream state or forecasting workflows.
interval
The sampling frequency in minutes for the source rows that feed a feature family.
behavioral axis
A conceptual domain for clustering or state interpretation, such as trend, volatility, activity, breadth, dispersion, or relationship exposure.
relationship edge
A source row describing a measured relationship between an asset and a related asset or benchmark.
